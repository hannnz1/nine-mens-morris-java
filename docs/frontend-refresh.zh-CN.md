# 前端体验调整（2026-09-17）

项目保持原生 HTML、CSS、JavaScript，无新增框架或 CDN 依赖。

## 修改内容

- 入口收紧标题与卡片间距，创建和加入并列；仅有保存的身份或待确认加入请求时显示恢复卡片。返回入口保留身份，清除身份仍需要明确确认。
- 复制邀请链接只包含 game 参数，不含玩家凭证；复制失败时显示可选中的链接。原有编号加入继续可用。
- 棋局采用棋盘为主、玩家和控制区为辅的两列布局。手机按棋盘、玩家动态、控制区排列，保留连接状态文字。
- 玩家卡明确区分待落数量与在盘数量，标注自己的身份和当前回合；界面使用中文。
- 区分可选棋子、选中棋子和空目标。只在相邻版本变化时标记发生变化的棋位坐标，不根据跨版本快照猜测最后一步。
- 未确认操作持续展示说明和原请求重试入口，优先于等待对手提示。
- 快照成功不再显示为实时在线：只有已确认订阅且快照成功时显示实时连接，否则显示快照同步。此状态不代表对方在线。
- 游戏规则默认展开；技术架构与版本号置于可展开的演示说明。支持键盘焦点与减少动画设置。

## 面试说明

我优先改善用户能否理解当前状态和安全恢复操作，而不是引入新的前端框架。页面把实时连接与快照同步分开显示，网络不确定时保留原请求重试，避免界面让用户误以为操作失败后可以重新落子。邀请只传递棋局编号，身份凭证留在当前标签页。代价是没有账号跨设备恢复，也没有对手在线状态；对于双人面试演示，这些限制比引入完整账号和在线状态系统更合适。
