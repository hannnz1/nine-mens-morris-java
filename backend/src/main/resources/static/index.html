    一分钟了解规则
    1. 轮流落子：双方各九子，白方先手，放在空的交点上。
    2. 三子成磨：沿棋盘连线形成三子一线，可移除对方一子。优先移除不在磨中的棋子。
    3. 移动与飞行：落子结束后沿线移动；只剩三子时可飞到任意空位。
    4. 赢下对局：对方落子结束后不足三子，或无合法移动时获胜。
